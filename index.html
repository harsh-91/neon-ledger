Mac beta

Statement Importer now has separate beta builds for Apple Silicon and Intel Macs. Download the ZIP for your Mac, then install PostgreSQL 17 with Homebrew or Postgres.app before setting up local storage.

SHA-256 Intel: f16b14a589a6fc9a8f5ef4e61ad3871c924ff824101fcac00cba97e06703782a

Unsigned beta: these builds have no Apple Developer ID signature or notarization, so macOS may block a downloaded copy. Install only if you trust the official GitHub release and verify its SHA-256 checksum. This beta requires macOS 15 or newer and an unlocked login Keychain. The graphical app has not yet been exercised on a physical Mac. Back up important data before using it.

Use the app in four steps

01

Install

On Windows, run setup and follow any prerequisite prompts. On Mac, extract the ZIP, move the app to Applications, and install PostgreSQL 17 tools before opening it.

02

Set up

Click Set up storage and continue. See the current step and elapsed time as your database is prepared. The importer opens when ready; existing-server settings remain under Advanced.

03

Import

Select one or many CSV, XLS or XLSX statements. Add a per-file or batch password only when a statement is encrypted.

04

Review

Check reconciliation results, skipped duplicates, import history and the unified transaction view before reporting.

Requirements

  • Windows 10 build 17763+ or Windows 11
  • Windows x64: PostgreSQL and Microsoft Edge WebView2
  • Mac beta: macOS 15+ on Apple Silicon or Intel, PostgreSQL 17 tools, and an unlocked login Keychain

Query the result

Use the app’s transaction browser, or connect DBeaver to PostgreSQL and query unified_bank_transactions. Create a read-only reporting login from the app’s Safety screen when sharing database access.

Windows signing status: this release is currently unsigned, so Microsoft SmartScreen may show “Unknown publisher.” Verify the checksum below before running it and review the code signing policy.
Upgrading Windows? Finish imports and make a database backup. Version 1.6.3 users can check, download, and open 1.6.4 from Updates. Earlier versions need to download and run the installer here. You do not need to uninstall the old version. Setup shows progress while closing the previous copy and asks permission if it needs to force it to close.

Updates without surprises

Version 1.6.3 adds in-app update checks and verified downloads for Windows and Mac. On Mac, the verified ZIP opens in Finder for you to replace the app in Applications.

Windows update checks

An automatic check only reads public release metadata. The Windows app never downloads or installs an update silently; both actions require your click.

Verified downloads

The app checks the official GitHub asset digest, size, and published SHA-256. Windows blocks invalid signatures and labels unsigned beta installers before you choose to open them. Mac opens the verified ZIP in Finder for manual replacement.

Private bug reports

On Windows or Mac, open Diagnostics, create a report, review the exact fields, then describe and send the issue. No GitHub account or email app is needed. The ZIP and financial data stay local.

OFFLINE STAYS OFFLINE // Local importing and diagnostics work without internet. Sending a bug report requires your review, confirmation and an internet connection. Version 1.6.3 and later can check and verify newer releases in Updates; earlier versions need a manual upgrade to 1.6.4. Microsoft Store delivery remains pending approval.

REST API + MCP

Give reporting tools and AI clients read-only access to normalized transactions. Open API / MCP inside Statement Importer, generate a key, then enable only the service you need.

REST API

Use the key as X-API-Key or a Bearer token. The OpenAPI document helps compatible tools discover every route.

Base: http://127.0.0.1:8765/api/v1
Schema: http://127.0.0.1:8765/api/v1/openapi.json
  • banks
  • accounts
  • transactions
  • balances
  • imports
  • schema

MCP server

Add the endpoint to an HTTP MCP client and send Authorization: Bearer YOUR_KEY. Your AI can then call the read-only tools you approve.

HTTP MCP: http://127.0.0.1:8765/mcp
  • list_banks
  • list_accounts
  • search_transactions
  • get_account_balances
  • get_import_history
  • get_transaction_schema

Which connection should I use?

REST API
Best for custom apps, scripts, Excel/Power Query and HTTP-capable BI tools.

MCP
Best for compatible AI assistants that need structured tools instead of unrestricted database access.

Direct PostgreSQL
Best for DBeaver, Power BI and Tableau. Use the app-generated read-only reporting user.

CSV export
Best for a quick offline handoff when a live connection is unnecessary.

LOCAL BY DEFAULT // Both services start disabled, require a generated key, are rate-limited and listen only on 127.0.0.1. Other computers cannot connect unless you deliberately change the architecture.
