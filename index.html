Use it in four steps

01

Install

Run the Windows setup. Missing PostgreSQL or WebView2 downloads are selected automatically when internet access is available.

02

Set up

Click Create my local database automatically. No host, port, database name, username or password is required. Existing-server settings remain under Advanced.

03

Import

Select one or many CSV, XLS or XLSX statements. Add a per-file or batch password only when a statement is encrypted.

04

Review

Check reconciliation results, skipped duplicates, import history and the unified transaction view before reporting.

Requirements

  • Windows 10 build 17763+ or Windows 11
  • 64-bit Intel or AMD computer
  • PostgreSQL and Microsoft Edge WebView2

Query the result

Use the app’s transaction browser, or connect DBeaver to PostgreSQL and query unified_bank_transactions. Create a read-only reporting login from the app’s Safety screen when sharing database access.

Windows signing status: this release is currently unsigned, so Microsoft SmartScreen may show “Unknown publisher.” Verify the checksum below before running it and review the code signing policy.

REST API + MCP

Give reporting tools and AI clients read-only access to normalized transactions. Open API / MCP inside Statement Importer, generate a key, then enable only the service you need.

REST API

Use the key as X-API-Key or a Bearer token. The OpenAPI document helps compatible tools discover every route.

Base: http://127.0.0.1:8765/api/v1
Schema: http://127.0.0.1:8765/api/v1/openapi.json
  • banks
  • accounts
  • transactions
  • balances
  • imports
  • schema

MCP server

Add the endpoint to an HTTP MCP client and send Authorization: Bearer YOUR_KEY. Your AI can then call the read-only tools you approve.

HTTP MCP: http://127.0.0.1:8765/mcp
  • list_banks
  • list_accounts
  • search_transactions
  • get_account_balances
  • get_import_history
  • get_transaction_schema

Which connection should I use?

REST API
Best for custom apps, scripts, Excel/Power Query and HTTP-capable BI tools.

MCP
Best for compatible AI assistants that need structured tools instead of unrestricted database access.

Direct PostgreSQL
Best for DBeaver, Power BI and Tableau. Use the app-generated read-only reporting user.

CSV export
Best for a quick offline handoff when a live connection is unnecessary.

LOCAL BY DEFAULT // Both services start disabled, require a generated key, are rate-limited and listen only on 127.0.0.1. Other computers cannot connect unless you deliberately change the architecture.
